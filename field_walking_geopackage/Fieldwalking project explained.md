# Layers
## Fieldwork recording — fieldwalking_find
Geometry = Point
CRS = 27700 British National Grid
### Attributes
#### Find Number (integer)
This field is used to record a unique find number. It is possible to add a custom user expression to automatically number this field but I have intentionally left it blank so that the recorder can assign whatever unique number they wish. As a matter of good practise - each find should be given its own unique identifier so that any further specialist info may be related to the spatial layer
